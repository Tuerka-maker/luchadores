# Misión 2: dale corazón al Rey

### @diffs true

## Paso 1: el circuito de la corona @showdialog
La corona del rey toca dos tiras de cobre. Así se cierra el circuito.
Si la corona cae, el circuito se abre. El Núcleo lo nota.
Hoy vas a hacer el programa que lo vigila.
¿Ves los bloques en inglés? Pide ayuda: engranaje ⚙, luego **Language** y **Español**.

## Paso 2: para siempre
Pon un bloque **para siempre**. Lo que pongas dentro se repite sin parar.

```blocks
basic.forever(function () {
})
```

## Paso 3: si / si no
Dentro de **para siempre**, pon un **si / si no**.

```blocks
basic.forever(function () {
    if (true) {
    } else {
    }
})
```

## Paso 4: pregunta por la corona
Pon «corona [ ] puesta» en la condición del **si**. Elige **A**.

```blocks
basic.forever(function () {
    if (rey.coronaPuesta(Jugador.A)) {
    } else {
    }
})
```

## Paso 5: corona puesta
Dentro del **si**, muestra un **corazón**.

```blocks
basic.forever(function () {
    if (rey.coronaPuesta(Jugador.A)) {
        basic.showIcon(IconNames.Heart)
    } else {
    }
})
```

## Paso 6: corona caída
Dentro del **si no**, muestra una **X**.

```blocks
basic.forever(function () {
    if (rey.coronaPuesta(Jugador.A)) {
        basic.showIcon(IconNames.Heart)
    } else {
        basic.showIcon(IconNames.No)
    }
})
```

## Paso 7: un sonido
Debajo de la **X**, pon una nota corta.

```blocks
basic.forever(function () {
    if (rey.coronaPuesta(Jugador.A)) {
        basic.showIcon(IconNames.Heart)
    } else {
        basic.showIcon(IconNames.No)
        music.play(music.tonePlayable(262, music.beat(BeatFraction.Quarter)), music.PlaybackMode.UntilDone)
    }
})
```

## Paso 8: predice @showdialog
Si quitas la corona de A, ¿qué verás en la pantalla? Dilo antes de probar.

## Paso 9: conecta
Conecta el Núcleo al computador con el cable USB.

## Paso 10: descarga
Pulsa **Descargar**. La primera vez, elige el micro:bit y pulsa **Conectar**.

## Paso 11: prueba
Quita la corona de A y mira la pantalla. ¿Acertaste?
Si no cambia, revisa que la corona toque las dos tiras de cobre.

## Paso 12: explícaselo a un adulto @showdialog
¿Por qué el Núcleo sabe que la corona cayó?
Pista: piensa en el circuito abierto y el circuito cerrado.
